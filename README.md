# Gramer Pothe (গ্রামের পথে)

A bicycle ride down a kacha village road in Bangladesh: paddy fields, khals, tea stalls, chickens, cows and the odd village van. Ride it as a game, or as a quiet Zen ride while the day turns to night.

**Play: https://eachmoon303030.github.io/gramerpothe-web/**

Best in landscape. On a phone, use your browser's "Add to Home Screen" to install it; it then works offline.
